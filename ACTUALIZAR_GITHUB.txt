4. Copia TODOS los archivos y carpetas de Laura_Hernandez_Portfolio dentro de la carpeta del repositorio, donde está index.html. Reemplaza los existentes. No copies la carpeta contenedora ni el ZIP.
5. GitHub Desktop: revisa Changes. Escribe Actualizar portfolio: Jäg Records en Summary.
6. Commit to main > Push origin.
7. Espera a que GitHub Pages termine de publicar. El enlace es el mismo. Si ves la versión antigua, Ctrl+F5.
